Calculation method: Weight-based follows the formula: Marker Length (in) × Marker Width (in) × GSM ÷ (1,550,000 × Order Qty). Wastage is applied as a percentage of base consumption.

📐 Formula Reference
Weight-based — Knit / GSM (kg)
Use when marker length and width are in inches and fabric GSM is known.
Marker Length (in) × Marker Width (in) × GSM
× (1 + Wastage % ÷ 100)
1,550,000 × Order Qty
Result: kg per garment. Per dozen: kg per garment × 12.
Length-based — Woven (Yards / Meters)
Use when the full-order total marker length is known; GSM and width are not required.
Total Marker Length (yd)
× (1 + Wastage % ÷ 100)
Total Garments Qty
Yards selected: Total Marker Length (yd) ÷ Total Garments Qty. Wastage is applied as × (1 + Wastage % ÷ 100). This uses the full-order total marker length, not a single marker length. Per dozen: per-garment result × 12.
Key factors: In length-based mode, enter the total marker length for the entire order in yards (e.g., 350 yd for 10,000 pcs), with all garment parts included. Width and GSM are not required. Per-piece consumption = Total Marker Length ÷ Total Garments Qty × (1 + Wastage % ÷ 100). Select Meters to convert the yard input to meters automatically.
