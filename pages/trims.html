04 / REFERENCE

Formula Reference

Review the calculation methods used by each trims calculator.

Thread Consumption

Stitch Count = Seam Length (m) × 39.3701 × SPI. Thread (m/pc) = Σ (Part Seam Length × Part Thread Ratio) × (1 + Wastage % ÷ 100)

Enter each garment seam separately. Standard ratios are reference values at 18 SPI; use measured ratios from the actual fabric, stitch and SPI for production accuracy.

Button Consumption

Buttons = Buttons per Piece × Order Qty × (1 + Extra % ÷ 100)

Purchase quantity is rounded up to the next whole piece.

Interlining Consumption

Area (m²/pc) = Length × Width × Qty ÷ 10,000 × (1 + Wastage % ÷ 100)

Full-order area = Wastage-adjusted Area per Piece × Order Qty.
