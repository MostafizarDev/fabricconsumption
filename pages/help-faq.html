BASIC WORKFLOW

How to use any calculator

Follow this checklist before relying on a calculation.

01

Choose the correct tool

Select the calculator that matches the garment, material or costing task. Do not use a simplified estimate as a substitute for approved marker data.

02

Confirm units

Check every visible unit label before typing. Keep measurements consistent and convert values when changing between cm, inches, metres or yards.

03

Enter verified inputs

Use approved measurements, GSM, order quantity, component quantities, rates and wastage. Add allowances only where the calculator provides them.

04

Calculate and review

Use the calculator's Calculate control where provided. Check warnings, per-piece, per-dozen and order totals, then compare with approved factory data.

05

Export and keep a record

Use the available PDF or Excel export. Verify buyer, style, PO, units and inputs in the report before sharing it.

Production reminder

These tools support estimating and planning. Actual consumption can be affected by marker efficiency, fabric relaxation, shrinkage, cutting loss, fabric construction and factory practice. Confirm important figures against approved patterns, markers, tests and supplier information.

01Marker ConsumptionMarker-based fabric consumption by length or weight

What it does

Calculates per-garment, per-dozen and full-order consumption from one or more marker/fabric rows. Fabric-wise results group rows with the same fabric name.

How to use it

  1. Enter the order quantity as a positive whole number.
  2. Select the appropriate calculation method: length-based or weight-based.
  3. Add a row for each marker part or fabric. Enter its part name and fabric name.
  4. For length-based mode, enter total marker length and wastage. For weight-based mode, enter marker length, width, GSM and wastage.
  5. Check the selected output unit, calculate, then review order, per-piece, per-dozen and fabric-wise summaries.
  6. Download the PDF report if required.

Calculation reference

Weight-based modeBase kg/pc = (Marker Length × Width × GSM) ÷ (1,550,000 × Order Qty)Final kg/pc = Base kg/pc × (1 + Wastage % ÷ 100)Length-based modeBase consumption/pc = Total Marker Length ÷ Order QtyWhen output is metres: yards × 0.9144 ÷ Order QtyFinal consumption = Base consumption × (1 + Wastage % ÷ 100)Per dozen = Per-piece consumption × 12Order total = Per-piece consumption × Order Qty

Weight-based mode uses the tool's inch-based marker dimensions and the 1,550,000 divisor. In length-based mode, width and GSM are not used. Wastage is applied separately to each row.

02Knit GarmentsBody, collar, cuff, pocket and half-moon fabric consumption

What it does

Estimates knit garment fabric consumption from selected garment components. Each component has its own measurements, GSM and wastage setting.

How to use it

  1. Enter the order quantity and select the measurement unit (cm or inch).
  2. Select the components that apply to the garment.
  3. Enter each component's actual measurement and allowance values, plus its GSM.
  4. Enter the wastage percentage for each component.
  5. Review the component and total results. Unselected components are not included.
  6. Use the available PDF report control to export the calculation.

Calculation reference

Unit divisor used by the calculatorInch input: 1,550,000Centimetre input: 10,000,000Main body per piece((Body Length + Sleeve Length) × Half Chest × 2 × GSM) ÷ DivisorCollar per piece(Collar Length × Collar Width × GSM) ÷ DivisorCuff per piece(Cuff Length × Cuff Width × 2 × GSM) ÷ DivisorPocket per piece(Pocket Length × Pocket Width × Pocket Quantity × GSM) ÷ DivisorHalf-moon per piece(Half-moon Length × Half-moon Width × GSM) ÷ DivisorPer dozen before wastage = Per-piece amount × 12After wastage = Base amount × (1 + Wastage % ÷ 100)

The calculator adds the entered allowance to the corresponding measurement before applying the formula. Order quantity is used to calculate the order total; each component's wastage is applied to that component.

03Knit PantQuick Estimate and component-wise panel-area calculation

Choose a calculation method

Quick Estimate is a preliminary estimate using inseam, rise, waistband height, half-thigh and GSM. Component-wise calculates selected panels individually from length, width, quantity and GSM.

How to use it

  1. Enter a whole-number order quantity and choose cm or inch.
  2. Select Quick Estimate or Component-wise mode.
  3. For Quick Estimate, enter inseam, front crotch/rise, waistband height, half-thigh and GSM, including allowances where provided.
  4. For Component-wise, select the required panels and enter each row's length, width, quantity, GSM and wastage. Add allowances where available.
  5. Review the validation messages and result summary. Every selected component must have valid inputs.
  6. Use the report option when you need a calculation record.

Calculation reference

Quick Estimate (measurements converted to cm)Base kg/dozen = (Inseam × Half-thigh × 4 × GSM × 12) ÷ 10,000,000In the actual estimate, inseam is combined with rise and waistband height.Base kg/pc = Base kg/dozen ÷ 12Final kg/pc = Base kg/pc × (1 + Wastage % ÷ 100)Component-wiseCut length = (Length + Length Allowance) converted to cmCut width = (Width + Width Allowance) converted to cmArea (m²) = Cut Length × Cut Width × Component Qty ÷ 10,000Net kg = Area × GSM ÷ 1,000Final kg = Net kg × (1 + Component Wastage % ÷ 100)

Quick Estimate is explicitly preliminary and does not model the actual shape of every panel or marker layout. Verify it against the approved pattern, actual panel area or CAD marker before production. The tool's Component-wise result is also an area-based estimate and does not model nesting, marker efficiency, shrinkage or cutting loss.

04Woven ShirtBody, sleeve and additional component consumption

How to use it

  1. Enter order quantity and choose cm or inch.
  2. Enter body length, half chest, sleeve length, armhole and fabric width. Add measurement allowances where required.
  3. Enter the main body/sleeve wastage percentage.
  4. Add any extra components and enter each component's length, width, quantity and individual wastage.
  5. Review total order, per-piece and per-dozen results, including the component breakdown.
  6. Save a recent calculation or download its PDF report if those controls are available.

Calculation reference

Fabric width dividerDivider = Fabric Width × 36 × 2.54Main body per dozenBody = Body Length (cm) × Half Chest (cm) × 2 × 12 ÷ DividerSleeve per dozenSleeve = Sleeve Length (cm) × Armhole (cm) × 4 × 12 ÷ DividerAdditional component per dozenComponent = Length (cm) × Width (cm) × Component Qty × 12 ÷ DividerFinal order amount = Net order amount × (1 + Applicable Wastage % ÷ 100)Per piece = Final order amount ÷ Order Qty

The calculator converts entered measurements to centimetres internally. Main body/sleeve wastage and each additional component's wastage are applied separately.

05Booking SheetOrder details, size ratios, fabric rows and booking requirement

How to use it

  1. Enter buyer, style, PO, description, body fabric, order quantity, cut quantity and shipment information.
  2. Set the size names and enter each size ratio. The sum of the size ratios is used as the marker PCS count.
  3. Add a fabric row for each part/fabric and enter marker length, length allowance, marker width, width allowance, GSM and cut/wastage percentage.
  4. Review the automatically synchronized PCS count in each fabric row.
  5. Check net marker kg, net kg/dozen, final kg/dozen and total order requirement.
  6. Review the fabric-wise summary and export the available PDF or Excel booking report.

Calculation reference

Net marker kg = ((Marker Length + Length Allowance) × (Marker Width + Width Allowance) × GSM) ÷ 1,550,000Net kg/dozen = Net marker kg × 12 ÷ Marker PCSFinal kg/dozen = Net kg/dozen × (1 + Cut % ÷ 100)Grand kg/dozen = Sum of all fabric-row final kg/dozenOrder requirement (kg) = Grand kg/dozen × Total Order Qty ÷ 12

The booking calculator synchronizes the PCS field in every fabric row with the total of the size ratios. Check the ratio total and all fabric-row allowances before exporting.

06Knit Fabric CostFabric length and price per metre from kg, GSM and width

How to use it

  1. Open Pricing & Costing and choose Knit Fabric Cost.
  2. Enter fabric weight in kg, GSM, fabric width in metres and price per kg.
  3. Select the currency supported by the calculator.
  4. Review fabric length and price per metre, then download the PDF report if required.

Calculation reference

Fabric Length (m) = Fabric Weight (kg) × 1,000 ÷ (GSM × Width (m))Price per metre = Price per kg × GSM × Width (m) ÷ 1,000

The calculator requires positive fabric weight, GSM and width. Price per kg may be zero but must be entered. Width must be supplied in metres.

07FOB CostingManufacturing cost, overhead, profit, C&F and CIF

How to use it

  1. Open Pricing & Costing and choose FOB Costing.
  2. Enter fabric, trims, cut-and-make and accessories cost per piece.
  3. Enter overhead percentage and profit percentage.
  4. Enter freight per piece and insurance percentage.
  5. Review manufacturing cost, FOB, C&F and CIF. Confirm the selected currency and assumptions before exporting the PDF report.

Calculation reference

Total Manufacturing Cost = Fabric + Trims + Cut & Make + AccessoriesCost with Overhead = Total Manufacturing Cost × (1 + Overhead % ÷ 100)FOB = Cost with Overhead × (1 + Profit % ÷ 100)C&F = FOB + Freight per pieceCIF = C&F × (1 + Insurance % ÷ 100)

Enter all monetary inputs in the same selected currency and on the same per-piece basis. The calculator applies overhead and profit sequentially.

08Zipper Consumption PlannerFinished zipper length, order quantity, wastage and estimated cost

How to use it

  1. Enter order information and total order quantity.
  2. Choose Body / Neck Formula or Direct Measurement.
  3. For formula mode, enter body length, front neck drop and high neck. For direct mode, enter the measured finished zipper length.
  4. Enter shrinkage, zippers per garment and wastage. Add unit price if you want an estimated cost.
  5. Review total zipper quantity, total length and estimated cost, then download the report if needed.

Calculation reference

Body / Neck Formula methodBase length = Body Length + High Neck − Front Neck DropDirect Measurement methodBase length = Direct measured lengthFinished length (cm) = Base length (cm) × (1 − Shrinkage % ÷ 100)Base quantity = Order Qty × Zippers per GarmentTotal zipper quantity = CEILING(Base quantity × (1 + Wastage % ÷ 100))Total length = Finished length per zipper × Total zipper quantityEstimated cost = Total zipper quantity × Unit Price

When the input unit is inches, the entered length is converted to centimetres internally. Shrinkage must be below 100%; wastage can be from 0% to 100%. Cost is estimated only when a unit price is entered.

09Trims CalculatorSewing thread, buttons and interlining

Choose a trims calculator

Enter the order quantity, then select Thread, Button or Interlining. Each calculator has its own inputs and results.

Thread: how to use it

Add sewing operations and enter the operation length, rows and the applicable ratio, or use the Actual method with sample and measured thread values. If using component split, enter the relevant component ratios. Enter wastage and review per-piece, per-dozen and order totals.

Operation base = Operation Length × Number of RowsActual ratio = Measured Thread ÷ Sample ThreadOperation thread = Operation base × Applicable RatioNet thread/pc = Sum of operation threadFinal thread/pc = Net thread/pc × (1 + Wastage % ÷ 100)Per dozen = Per-piece thread × 12Order thread = Per-piece thread × Order Qty

Buttons: how to use it

Enter button pieces per garment and extra percentage. The calculator rounds the dozen and order requirements up to whole buttons.

Buttons/pc = Buttons per garment × (1 + Extra % ÷ 100)Buttons/dozen = CEILING(Buttons/pc × 12)Order buttons = CEILING(Buttons/pc × Order Qty)

Interlining: how to use it

Enter length, width, number of pieces per garment and wastage.

Net area/pc (m²) = Length × Width × Pieces ÷ 10,000Final area/pc = Net area/pc × (1 + Wastage % ÷ 100)Per dozen = Final area/pc × 12Order area = Final area/pc × Order Qty

Check the measurement units shown by each trims input before entering values. Thread output can be displayed in metres or yards. Button quantities are whole pieces; interlining results are area-based.

10Size Ratio & Assortment PlannerSize distribution, colors, marker lays and carton packing

How to use it

  1. Enter the order quantity and create or load the required size list.
  2. Choose Ratio or Percentage mode and enter the buyer's size distribution.
  3. In Percentage mode, ensure the percentages total 100%. In Ratio mode, enter positive ratio weights.
  4. Run the calculation and check that all size quantities add up to the order quantity.
  5. Optionally configure color-wise ratios, marker pieces per lay and carton capacity/packing mode.
  6. Review color, marker and carton summaries, then export the available report.

Calculation reference

Ratio modeRaw size qty = Order Qty × Size Ratio ÷ Sum of All Size RatiosPercentage modeRaw size qty = Order Qty × Size Percentage ÷ 100Whole-piece allocationTake the floor of each raw quantity, then assign remaining pieces to the largest fractional remainders.

The allocation method keeps the final size quantities equal to the entered order quantity. Duplicate size names are not allowed. The planner also includes optional color, marker-lay and carton-planning calculations.

11Measurement & Consumption ConverterLength, weight, fabric, GSM, yarn count and other unit conversions

How to use it

  1. Choose a conversion category in the quick converter.
  2. Choose the From and To units.
  3. Enter a value. The quick converter updates the result and displays the conversion equation.
  4. For dedicated garment/fabric converters, enter the requested values such as kg, GSM, width or length.
  5. Check the output unit beside every result before using it in another calculator.

Selected calculation references

Kg to metres = kg × 1,000 ÷ (GSM × Width in metres)Metres to kg = Metres × GSM × Width in metres ÷ 1,000Yards to kg = Yards × 0.9144 × GSM × Width in metres ÷ 1,000Kg/dozen = Kg/pc × 12Yards/dozen = Yards/pc × 12Order base = Consumption per piece × Order QtyOrder total = Order base × (1 + Wastage % ÷ 100)

The quick converter supports multiple categories, including area, length, mass, temperature, time, volume, speed and others. The displayed equation is the best reference for the selected quick conversion.

12My WorkspaceSave notes, formulas, useful links and screenshots

How to use it

  1. Choose Quick Note, Formula, Useful Link or Screenshot / Image.
  2. Enter a title and optional label. Add the relevant text, URL or image.
  3. Save the item. Use the search and filters to find saved items later.
  4. Use copy/open/download actions on an item where available.
  5. Use Export Backup to create a backup file. Use Import Backup to restore or add items from a backup.

Where your data is stored

Notes, formulas and links are stored in this browser's local storage. Screenshot/image records are stored in this browser's IndexedDB. The current Workspace does not provide automatic cloud synchronization or an account-based cross-device library.

Export a backup before clearing browser data, changing browser profiles or moving to another device. Keep backup files somewhere safe.

QUICK ANSWERS

Frequently asked questions

Why is my result different from a manual calculation?

Check the selected method, units, measurement allowances, order quantity, GSM, wastage, ratios and rounding. Make sure both calculations use the same inputs and assumptions. Some tools intentionally provide a preliminary or area-based estimate rather than a CAD marker result.

Why does a result show a dash or validation warning?

A required field may be blank, zero or outside the permitted range. Read the message shown by the calculator, complete the highlighted inputs and calculate again. Some calculators require a whole-number order quantity or a percentage total of exactly 100%.

When should I include wastage?

Enter the wastage allowance required by your approved factory or buyer method. Do not add wastage twice if your source consumption already includes it. Some tools apply wastage separately by component or fabric row.

Can I change units after entering measurements?

Use the unit controls provided by the calculator and check the displayed labels after changing units. Some calculators convert entered values internally or when the unit is changed. Always verify the values and labels before calculating.

Are calculations saved automatically?

Saving behaviour differs by tool. Some calculators provide recent-calculation controls; My Workspace stores its own notes, formulas, links and images locally in the current browser. Do not assume that every calculator is automatically saved or synchronized online.

Will My Workspace sync to another computer?

No. The current Workspace uses browser storage on the device where the items were created. Export a backup and import it on the other device if you need to transfer your items.

Can I use the results as final production approval?

No. Treat results as planning or estimation support. Confirm fabric consumption, costing and trims against approved patterns, markers, samples, supplier information and factory procedures before production or purchasing.

How do I report a calculation issue or request help?

Open Contact Us and include the calculator name, steps, units, input values and a screenshot. Do not send passwords, payment details or confidential buyer, supplier or factory information.
