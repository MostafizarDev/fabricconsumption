REFERENCE

Calculation Formula

Quantity distribution uses proportional allocation with automatic rounding correction.

Ratio BasedSize Qty = Order Qty × Size Ratio ÷ Total Ratio
Percentage BasedSize Qty = Order Qty × Size % ÷ 100
Marker PlanningMarker Lays = MAX(CEIL(Size Order Qty ÷ Qty per Marker))
Carton PlanningCartons = FLOOR(Order Qty ÷ Carton Capacity)
