# Fabric Consumption

**A practical garment calculator suite for fabric consumption, material planning, and costing.**

Fabric Consumption brings commonly used apparel and garment-industry calculations into one browser-based workspace. It helps garment professionals organize calculation inputs, review results, and prepare useful reports without switching between multiple separate tools.

🌐 **Live Website:** https://fabricconsumption.vercel.app/

---

## Overview

Fabric Consumption is designed for everyday work in garment merchandising, fabric, production, technical, and costing teams. The tools support common planning tasks involving garment measurements, fabric consumption, marker details, order quantities, size ratios, trims, and costing.

The website runs in a modern web browser. Choose the relevant tool, enter your specifications, review the calculated results, and use the available report or export options.

## Tools & Features

| Tool | What it helps with |
|---|---|
| **Marker Consumption** | Work with marker-based fabric consumption and review calculated results. |
| **Knit Garments** | Calculate knit garment fabric consumption using garment measurements and available calculation settings. |
| **Knit Pant** | Estimate knit pant consumption through quick or component-based measurements. |
| **Woven Shirt** | Calculate woven shirt consumption using garment component measurements. |
| **Booking Sheet** | Organize order details, fabric information, marker details, and size ratios; prepare booking reports. |
| **Pricing & Costing** | Access the Knit Fabric Cost Calculator and FOB Costing tools. |
| **Zipper** | Plan zipper requirements using the available calculation inputs. |
| **Trims** | Work with thread, button, and interlining calculations. |
| **Size Ratio** | Distribute order quantities across sizes and review size-wise totals. |
| **Unit Converter** | Convert common length, weight, fabric, GSM, area, yarn-count, temperature, and production-related units. |
| **My Workspace** | Keep personal notes, formulas, links, and screenshots in the browser, with a backup export option. |

Additional report and download options are available in supported tools, including PDF and spreadsheet exports where provided by the calculator.

## How to Use

1. Open the [Fabric Consumption website](https://fabricconsumption.vercel.app/).
2. Select the calculator that matches your task.
3. Enter the required order details, measurements, units, and specifications.
4. Review the calculation results and assumptions.
5. Use the available PDF or spreadsheet download options when needed.

## Important Notes

- Enter accurate measurements and confirm the selected units before calculating.
- Review allowances, wastage, size ratios, and other production assumptions.
- Always verify important calculations before using them for purchasing or production decisions.
- Keep backups of important reports and information stored in your browser workspace.

Fabric Consumption is a calculation support tool. It does not replace approved patterns, production markers, fabric testing, supplier confirmation, or your organization's established production procedures. Actual results may vary depending on the inputs and methods used.
