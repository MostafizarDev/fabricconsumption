Calculation method: Weight-based follows the Excel-style formula: Marker Length (in) × Marker Width (in) × GSM ÷ (1,550,000 × Garments / Marker). Wastage is applied as a percentage of base consumption.

📐 Formula Reference
Weight-based — Knit / GSM (kg)
Use when marker length and width are in inches and fabric GSM is known.
Marker Length (in) × Marker Width (in) × GSM
× Wastage %
1,550,000 × Garments Qty
Result: kg per garment. Per dozen: kg per garment × 12.
Length-based — Woven / Length (yd, m)
Use when fabric consumption is based on marker length; GSM and width are not required.
Marker Length (in) ÷ 36 (for yards)
× Wastage %
Garments / Marker
For meters: Marker Length (in) × 0.0254 ÷ Garments / Marker, then apply waste. Per dozen: per-garment result × 12.
Key factors: Garments / Marker is the number of garment pieces represented by one marker. Waste is applied as a percentage of base consumption. Total order consumption = consumption per garment × Order Qty.

Formula Reference
Quick Estimate · Consumption per Piece
(Inseam + Rise + Waistband) × Half-thigh × 4 × GSM
× Wastage %
1,00,00,000 (CM)    or    15,50,000 (IN)
Allowances are added to their matching measurements. Factor 4 is a simplified panel-area assumption; this is a preliminary estimate, not a CAD marker result.
Component-wise · Each Component
Length × Width × Qty / garment × GSM
× Wastage %
1,00,00,000 (CM)    or    15,50,000 (IN)
Each selected component uses its own dimensions, quantity, GSM and wastage. Final garment consumption is the sum of the selected components.
Unit Conversion
CM input = value as entered
Inch input = value × 2.54 = cm
Both methods convert measurements to cm before calculating.
Order & Dozen Conversion
kg/dozen = kg/pc × 12
Order total kg = kg/pc × Order quantity
Wastage kg/pc = Final kg/pc − Before-wastage kg/pc
Accuracy note: Quick Estimate is approximate. For production approval, verify component dimensions and quantities against the approved pattern/CAD marker and actual factory consumption. Costing is excluded.
